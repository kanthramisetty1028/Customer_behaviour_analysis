📊 Customer Shopping Behavior – Data Analytics Project
Analyze customer shopping patterns using Python, SQL Server, and Power BI to uncover key business insights. This end-to-end project covers data cleaning, analysis, dashboarding, and storytelling—ideal for analytics and BI roles.

📂 Dataset Summary
- File: customer_shopping_behavior.csv
- Rows: 3900  Columns: 18
- Includes: Age, Gender, Category, Purchase Amount, Review Rating, Shipping, Payment, Discounts
  
🛠 Tools Used:
  Task           Tool
  Data analysis  Pyhton(pandas,jupiter)
  SQL Queries    SQL Server
  Dashboard      power BI
  Reporting      PDF
  Presentation   Gamma app
  
🔍 Project Workflow
- Data Cleaning – Null handling, category standardization, outlier removal
- EDA – Demographics, top products, seasonal trends, discount impact
- SQL Analysis – Revenue, segments, category breakdown, discount analysis
- Power BI Dashboard – KPIs, category sales, age trends, shipping/payment insights
- Reporting & Presentation – Summarized findings, visuals, recommendations

  ✅ Key Insights
- 👕 Clothing had highest sales
- 👥 Most customers aged 30–60
- 💳 PayPal & Credit Card were top payment methods
- ❄️ Winter & Spring saw peak sales
- 🎁 Discounts boosted purchase frequenc
